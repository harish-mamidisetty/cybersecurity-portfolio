PROJECT WRITE-UP / AUTHENTICATION SECURITY

DVWA Brute Force Lab

A controlled authentication lab comparing brute-force protections across DVWA security levels.

← Back to projects

Objective

Understand how weak login defenses make repeated password guessing easier and how layered controls slow or stop automated attempts.

Lab Approach

  • Captured and reviewed login requests using Burp Suite.
  • Compared response behavior and timing across security levels.
  • Observed the effect of request delays and anti-CSRF tokens.
  • Documented why consistent error messages and lockout controls matter.

What I Learned

Authentication defenses should not depend on one control. Rate limiting, MFA, safe lockout behavior, monitoring and token validation work together.

Mitigation

  • Apply rate limiting and progressive delays.
  • Use MFA for important accounts.
  • Monitor repeated failed logins.
  • Use consistent authentication error messages.
  • Protect state-changing flows with appropriate tokens.
This write-up documents practice performed only in an intentionally vulnerable or authorized lab environment.
