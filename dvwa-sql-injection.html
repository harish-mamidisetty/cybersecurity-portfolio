PROJECT WRITE-UP / WEB SECURITY

DVWA SQL Injection Lab

A practical lab write-up focused on understanding how unsafe database queries can expose application data and how secure coding prevents the issue.

← Back to projects

Objective

Understand how user-controlled input can influence a backend SQL query in a deliberately vulnerable application, then document the defensive lessons.

Lab Approach

  • Captured and reviewed application requests in Burp Suite.
  • Observed how changing an input parameter affected the server response.
  • Compared behavior across DVWA security levels.
  • Documented how validation and safer database access reduce the risk.

What I Learned

The exercise improved my understanding of request parameters, database-backed applications, error behavior and why parameterized queries are important.

Mitigation

  • Use prepared statements / parameterized queries.
  • Validate input using allow-lists where appropriate.
  • Avoid exposing detailed database errors to users.
  • Apply least-privilege database permissions.
This write-up documents practice performed only in an intentionally vulnerable or authorized lab environment.
