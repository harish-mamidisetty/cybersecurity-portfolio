PROJECT WRITE-UP / NETWORK ANALYSIS

Wireshark Network Traffic Analysis

A packet-analysis exercise focused on understanding common protocols, conversations and useful indicators visible in network traffic.

← Back to projects

Objective

Improve packet-analysis skills by reviewing network conversations and identifying how common protocols appear on the wire.

Lab Approach

  • Captured or opened lab packet traffic in Wireshark.
  • Used display filters to focus on specific protocols and hosts.
  • Reviewed TCP conversations, DNS lookups and HTTP-style request flows.
  • Connected packet-level observations to SOC-style investigation thinking.

What I Learned

Packet captures provide strong evidence for troubleshooting and security analysis. Filtering, following conversations and understanding protocol behavior are core analyst skills.

Defensive Takeaways

  • Monitor unusual destinations and repeated connection failures.
  • Correlate packet evidence with endpoint and SIEM logs.
  • Use encrypted protocols for sensitive traffic.
  • Baseline normal network behavior where possible.
This write-up documents practice performed only in an intentionally vulnerable or authorized lab environment.
