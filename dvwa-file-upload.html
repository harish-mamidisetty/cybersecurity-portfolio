PROJECT WRITE-UP / WEB SECURITY

DVWA File Upload Lab

A controlled lab exercise focused on insecure file-upload validation and defensive upload design.

← Back to projects

Objective

Understand why checking only a filename or MIME type is insufficient when accepting uploaded files.

Lab Approach

  • Compared upload behavior across DVWA security levels.
  • Reviewed filename extension and MIME-type validation.
  • Observed the value of checking actual file content.
  • Considered safe storage and execution controls for uploads.

What I Learned

Upload security requires layered validation. Even a valid-looking image type can be dangerous if executable content is stored where the web server can run it.

Mitigation

  • Allow-list extensions and verify real file content.
  • Generate server-side filenames.
  • Store uploads outside executable web paths.
  • Set restrictive permissions and size limits.
This write-up documents practice performed only in an intentionally vulnerable or authorized lab environment.
