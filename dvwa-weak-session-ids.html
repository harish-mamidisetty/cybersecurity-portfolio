PROJECT WRITE-UP / SESSION SECURITY

DVWA Weak Session IDs Lab

A lab exercise demonstrating why predictable session identifiers can weaken authentication and session management.

← Back to projects

Objective

Understand how predictable or low-entropy session identifiers can allow one user's session value to be guessed from another.

Lab Approach

  • Observed session identifier patterns generated by the application.
  • Compared predictable sequences with stronger random values.
  • Reviewed how entropy affects resistance to guessing.
  • Connected the findings to secure session-management practices.

What I Learned

Session identifiers should not reveal a sequence, timestamp or other predictable structure. Strong cryptographic randomness is essential.

Mitigation

  • Use cryptographically secure random session IDs.
  • Regenerate sessions after authentication changes.
  • Use Secure, HttpOnly and SameSite cookie attributes.
  • Expire sessions appropriately.
This write-up documents practice performed only in an intentionally vulnerable or authorized lab environment.
