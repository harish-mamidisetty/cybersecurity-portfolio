PROJECT WRITE-UP / WEB SECURITY

DVWA XSS Lab

A controlled lab exercise covering cross-site scripting concepts and how unsafe handling of browser-rendered input can create security issues.

← Back to projects

Objective

Understand how untrusted input can reach a browser response and why output encoding is essential for preventing script execution.

Lab Approach

  • Reviewed reflected and stored input behavior in DVWA.
  • Observed where user input appeared in the rendered page.
  • Compared application behavior at different security levels.
  • Focused on the defensive role of context-aware output encoding.

What I Learned

XSS is not only an input problem; the output context matters. HTML, attributes and JavaScript contexts require appropriate encoding and safe DOM APIs.

Mitigation

  • Apply context-aware output encoding.
  • Prefer safe DOM methods instead of unsafe HTML insertion.
  • Use Content Security Policy as an additional defense.
  • Validate input but do not rely on validation alone.
This write-up documents practice performed only in an intentionally vulnerable or authorized lab environment.
